How to set up a new Mac like your old one

Migration Assistant copies everything once, including what you'd rather leave behind. To start clean and still get your setup, install MacSync on the old Mac, let it save, then install it on the new one and press Apply: it brings the Dock, apps, settings, config files and developer setup, and keeps both Macs the same afterwards.

Download MacSync Free, macOS 13 or later.

Step by step

  1. On the old Mac, install MacSync and let it sync.
  2. On the new Mac, sign in to the same Apple Account and turn on iCloud Drive.
  3. Install MacSync and open Review Changes.
  4. Choose what you want and press Apply, then work through the sign-in list.

MacSync or Migration Assistant?

Migration Assistant moves accounts, documents and apps from one Mac to another, once. MacSync doesn't move documents; it keeps the setup of Macs you go on using the same.

MacSync or a Brewfile?

brew bundle installs what a file you maintain says. MacSync works out the list from what each Mac has, and also covers App Store and downloaded apps, the Dock, settings and config files.
