MacSync

How to sync dotfiles and AI tool setup across Macs

MacSync syncs config files (zsh, fish, bash, Git, VS Code, Cursor, Zed, Neovim, Ghostty) and AI setup (CLAUDE.md, AGENTS.md, skills, agents, rules and MCP servers) through your own iCloud Drive. Keys are taken out of MCP servers, and a config file containing a secret stays on its Mac.

Download MacSync Free, macOS 13 or later.

Step by step

  1. Install MacSync on each Mac.
  2. Open Config files and AI setup in the sync window.
  3. Read the lines that would change.
  4. Press Apply, then add each Mac's own keys where MCP servers need them.

Do I need a dotfiles repo?

No. There's no Git repository and no symlinks: MacSync reads the files where they are, and never replaces a newer edit of yours.

Editors and packages

VS Code and Cursor extensions, npm global packages, uv tools, Homebrew taps and Claude Code plugins are offered on the Macs that lack them.
